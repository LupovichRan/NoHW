# Nohomework

Nohomework is a Hebrew-first homework board. One admin looks after many schools. Each school has a principal, and each class has a teacher. The student checks the evening list and marks work done. The parent sees the week. The teacher posts homework for a subject, or marks that subject as having no homework. A subject with no post stays "not updated" and is never shown as "no homework".

This branch is a local-first pilot: a static PWA in `dist/`, with no database, no accounts, and no email. Data stays in the browser. People in the demo (נועם לוי, מיכל שפירא, and the rest) are fictional. The license is MIT. See [CONTRIBUTING.md](CONTRIBUTING.md) and [SECURITY.md](SECURITY.md).

# Nohomework — פיילוט מקומי

אפליקציית שיעורי בית בעברית, לטלפון. אדמין אחד מנהל כמה בתי ספר. לכל בית ספר יש מנהל, ולכל כיתה יש מורה. זו אפליקציית דפדפן שאפשר להתקין למסך הבית. אין שרת, אין חשבון ואין אימייל. כל הנתונים נשמרים במכשיר (localStorage). מעבר בין מכשירים נעשה בקובץ או בקישור, לא בבסיס נתונים.

התלמיד הוא המשתמש העיקרי. ההורה רואה את השבוע. המורה מפרסם לכל מקצוע: יש שיעורי בית, או סימון מפורש שאין. מקצוע בלי עדכון נשאר **לא עודכן** — הוא אף פעם לא מוצג כ«אין שיעורי בית».

## הרצה מקומית

```bash
cd dist && python3 -m http.server 8099
```

פותחים `http://localhost:8099`. בראש המסך כתוב שזה פיילוט מקומי בלי שרת. בתצוגת הדמו מחליפים תפקיד (הורה, ילד, מורה, מנהל, אדמין) ובוחרים אדם.

בדיקות:

```bash
for t in tests/*.cjs; do node "$t" || exit 1; done
```

## מה יש בפיילוט

- עץ ניווט: אדמין › בית ספר › כיתה › תלמיד והורה. לחיצה על צומת פותחת את הלוח של אותה רמה, ופירורי לחם מחזירים למעלה. כל תפקיד רואה רק את התת-עץ שלו.
- לוח אדמין: כל בתי הספר. הוספה ועריכה של בית ספר, ומינוי מנהל. כרטיסי סטטיסטיקה ופסים: שיעור עדכון, חלק «לא עודכן», ותלמידים פעילים — לכל בית ספר ולכולם.
- לוח מנהל: הכיתות של בית הספר שלו. הוספת כיתה ומינוי מורה, עם אותם פסים לכל כיתה.
- לוח מורה: התלמידים וההורים של הכיתה. הוספה, קוד כיתה וקוד הורה בוואטסאפ, ופסים לכל מקצוע (פורסם / הוכן) ולכל תלמיד.
- תלמיד והורה נשארים במסך הערב ובמסך השבוע, בלי לוח ניהול.
- תלמיד מצטרף עם קוד כיתה ושם פרטי בלבד. אין מספר זהות. הורה מתקשר עם קוד הורה, אחרי סימון הסכמה.
- מסך ערב לתלמיד עם סימון «הוכן», ומסך שבוע להורה.
- תמלול קולי (Whisper) וזיהוי טקסט מצילום נשארים אצל המורה. הסבר AI לתלמיד כבוי בכיתות ד׳–ז׳.
- עברית, אנגלית, רוסית וערבית. עברית וערבית מימין לשמאל.
- מדיניות פרטיות בעברית (`dist/privacy.html`) ומסך הסכמת הורה.

## שיתוף בין מכשירים

בבורר: «שיתוף בין מכשירים».

- קובץ JSON (`nohomework-pilot.json`) מייצא ומייבא את בית הספר, הכיתות, האנשים והעדכונים. בלי הקלטות ובלי תמונות.
- קישור `#pack=` עושה את אותו הדבר כשהחבילה קצרה מספיק. חבילה ארוכה יורדת כקובץ.
- קוד כיתה: `#join=CODE`. קוד הורה: `#parent=CODE`. קוד מורה: `#teach=CODE`.

וואטסאפ נפתח עם הטקסט מוכן. האפליקציה לא שולחת הודעה בעצמה.

## התקנה, אופליין ותזכורות

יש מניפסט ו-service worker. בהתקנה נשמרים קבצי האפליקציה, וגם ספריות ה-CDN של התמלול, הזיהוי והגופן (בלי משקלי המודלים, שהם גדולים). אחרי פתיחה אחת עם רשת, קבצים שכבר נטענו מ-jsDelivr נשארים במטמון.

אין דחיפה משרת (אין VAPID ואין Edge Function). תזכורת הערב היא מקומית, כל עוד האפליקציה פתוחה או שחוזרים אליה. באייפון: קודם «הוספה למסך הבית», פותחים מהאייקון, ואז לוחצים «הפעלת תזכורות ערב». בלי הלחיצה אין בקשת הרשאה.

## פרטיות

אין מספר זהות, אין חשבון ואין שליחה אוטומטית לשרת. ההורה מסמן הסכמה. הפירוט בעברית: [מדיניות הפרטיות](dist/privacy.html).

## תצוגה בטלפון (GitHub Pages)

הענף `cursor/nohw-pilot-775c` מוכן לפרסם את `dist/` ל-GitHub Pages. אחרי שמפעילים Pages עם מקור GitHub Actions, הכתובת היא `https://lupovichran.github.io/NoHW/`.

הקישורים באתר יחסיים. ב-`manifest.webmanifest` השדות `start_url`, `scope` ו-`id` הם `./`, ולכן הם מחושבים מתוך תיקיית המניפסט (`/NoHW/` ב-Pages, `/` בהרצה מקומית). ה-service worker נרשם מאותה תיקייה, והמטמון שלו משתמש בנתיבים יחסיים לקובץ `sw.js`. אין כאן פריסה ל-Cloudflare.

## פריסה

האתר הוא קבצים סטטיים מתוך `dist/`. `wrangler.jsonc` מצביע על Cloudflare Pages בשם `nohw`. לא לפרוס מהענף הזה אל הפרויקט החי בלי בדיקה. כשמחליטים לפרסם סביבת תצוגה:

```bash
npx wrangler pages deploy dist --project-name nohw
```

זה מחליף את האתר שבפרויקט `nohw`. לפרוס לפרויקט אחר אם הפרודקשן צריך להישאר כמו שהוא.
